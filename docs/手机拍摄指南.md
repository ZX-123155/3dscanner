# 手机拍摄指南

## 一、拍摄准备

### 设备要求
- 手机：任何主流手机（建议 1200 万像素以上）
- 辅助：稳定的手持姿势或三脚架（推荐）

### 拍摄环境
- **光照**：均匀、柔和的自然光或室内灯光；避免强逆光、阴影剧烈变化
- **背景**：纹理丰富但不过于杂乱（书架、地板花纹都行）；避免纯白/纯黑墙
- **物体**：不反光、不透明效果最好；玻璃、金属等反光物体需要多角度补拍

## 二、拍摄方法（关键！）

### 环绕拍摄法（推荐，适用中小物体）
1. 物体放在桌面或地面上
2. 手机保持与物体大致同一高度，距离物体约 0.5~1 米
3. 围着物体**缓慢走一圈**，每走一步拍一张
4. 相邻两张照片的重叠区域要 **60% 以上**（走一步拍一张，别走快了）
5. 一圈 20~40 张

### 多层次拍摄（完整重建）
- 在**三个高度**各拍一圈：略俯视、平视、略仰视
- 总张数：30~150 张

### 拍摄注意事项
- ✅ 拍照时**不要走动**，站稳再拍，避免模糊
- ✅ 保持相同的缩放倍数（别一会儿 1x 一会儿 2x）
- ✅ 让物体始终在画面中央附近
- ❌ 不要用超广角（画面边缘畸变大）
- ❌ 不要拍镜面反射的物体（重建会失败）
- ❌ 不要拍运动中的物体
- ❌ 画面里不要出现你的手/影子

## 三、照片传输

### 方式一：局域网直传（推荐，手机连同一 WiFi）
电脑和手机连**同一个 WiFi**，然后：

1. 电脑上启动上传服务：
   ```bash
   cd C:\Users\luyicheng\Desktop\3dscanner
   C:\Users\luyicheng\miniconda3\envs\3dscanner\python.exe scripts/upload_server.py
   ```
   > ⚠️ 不要用 `conda run -n 3dscanner python ...`：该环境带 CUDA 激活脚本，在 conda run 下会报 "Did not find VSINSTALLDIR" 而无法启动。直接用上面的 python 绝对路径即可。
   启动后会显示类似 `http://192.168.1.5:8000` 的地址（电脑的局域网 IP）
2. 手机浏览器打开这个地址（iPhone/安卓自带浏览器都行）
3. 页面里**选择照片（可多选）→ 上传**，照片直接存到电脑 `input/` 文件夹
4. 全部传完后，点页面上的 **"开始重建"** 按钮，电脑自动跑 COLMAP + 3DGS 全流程
5. 页面下方能看到实时重建日志

> 优点：不走微信/QQ、不压缩画质、不用插数据线、传完一键重建
> 如果手机打不开页面，通常是 Windows 防火墙拦截，首次启动时允许访问即可

### 方式二：微信文件传输助手
1. 手机微信 → 文件传输助手 → 发送照片
2. 电脑微信 → 文件传输助手 → 右键图片 → 另存为
3. 全部保存到 `3dscanner/input/` 文件夹

### 方式三：数据线
1. 手机连接电脑，选择"传输文件"
2. 找到 DCIM/Camera 目录，把照片复制到 `3dscanner/input/`

### 方式四：QQ
同微信，通过"我的手机"发送到电脑端。

## 四、一键重建

照片放进 `input/` 后，运行：

```bash
cd C:\Users\luyicheng\Desktop\3dscanner
conda activate 3dscanner
python scripts/pipeline.py --input input --output output --model models/3dgs
```

等待 10~30 分钟（视照片数量），完成后：
- 点云：`output/sparse.ply`
- 3DGS 模型：`models/3dgs/model.ply`
- 环绕视频：`models/3dgs/orbit.mp4`

## 五、常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 重建出的点云残缺 | 照片重叠不够 / 角度太少 | 多拍一圈，放慢速度 |
| 点云全是噪点 | 背景太杂乱 / 光照不均 | 换背景，均匀补光 |
| 3DGS 渲染模糊 | 照片太少或模糊 | 增加照片，重拍模糊的 |
| 重建失败（点太少） | 物体无纹理 | 给物体贴些有纹理的贴纸 |
