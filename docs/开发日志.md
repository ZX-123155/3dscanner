### 技术要点
- COLMAP 4.1.1 参数与旧版不同：`--SiftExtraction.use_gpu` 已改为 `--FeatureExtraction.use_gpu`；匹配参数改为 `--FeatureMatching.use_gpu`
- COLMAP 4.x 新模型格式（frames.bin/rigs.bin）不能直接给 3DGS 用，需 `model_converter --output_type BIN` 转标准格式
- 项目脚本删除旧目录时不能直接 rmtree（WorkBuddy 沙箱会拦截删除），改用重命名备份策略
- 108 张输入图（im_0001~im_0108.JPG，2272×1704）
- gsplat 1.5.3 已移除 simple_trainer 和 ssim，需自写训练脚本（pycolmap 加载数据 + gsplat rasterization）
- gsplat 需要 CUDA toolkit 做 JIT 编译：conda 装 cuda-nvcc/cuda-cudart-dev/cuda-cccl（12.1）；3060 设 TORCH_CUDA_ARCH_LIST=8.6
- **关键坑**：WorkBuddy 的 sitecustomize 钩子拦截 shutil.rmtree（走回收站），gsplat JIT 编译清理缓存目录会失败 → 需 `PYTHONPATH=` 清空后直接调用环境 python.exe 绕过
- COLMAP 稠密重建：image_undistorter 输入需指向 sparse/0（模型实际位置）
- pycolmap 4.1.1 API：cam_from_world() 是方法、rotation.quat 是 [x,y,z,w]、track.elements 是 list

### 脚本
- `scripts/run_colmap.py`：特征提取 → 穷举匹配 → 稀疏重建 → 模型转换 → 稠密重建（可选）
- `scripts/train_3dgs.py`：pycolmap 加载 → gsplat 训练（自实现 SSIM）→ 环绕渲染 → PLY 导出
- `scripts/pipeline.py`：一键全流程
