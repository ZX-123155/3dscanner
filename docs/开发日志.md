### 训练黑屏问题定位（关键！）
1. **K 内参必须随图像缩放**：max_size 缩放图像后 fx/fy/cx/cy 要乘 s，否则投影全在画面外
2. **gsplat rasterization 不自动激活参数**：
   - scales 需传 `torch.exp(scales)`（优化器操作对数空间）
   - opacities 需传 `torch.sigmoid(opacities)`（优化器操作 logit 空间）
   - 直接传原始值 → opacity≈0 → 全黑 → 梯度 0 → 训练无效（loss 恒定 0.40）
3. **sh_degree 用 None**（直接 RGB），不要用 0 + (N,1,3) SH 系数（1.5.3 梯度有问题）
4. **orbit 相机旋转矩阵 z 轴 = forward**（OpenGL 约定相机看向 -z），不是 -forward
5. 稠密重建（patch_match）108 张 2272×1704 图非常耗时（3.5h+ 未完成），且与 3DGS 训练抢 GPU，验证阶段可跳过
6. 渲染/训练输出日志编码乱码是 GBK 控制台问题，不影响功能

### gsplat 编译踩坑记录（重要）
1. gsplat 1.5.3 需要 CUDA toolkit JIT 编译，conda 装 cuda-nvcc 等组件
2. MSVC 14.44 太新：CUDA 12.1/12.4 报 STL1002 → 必须 CUDA 12.6+
3. safe-delete 钩子会破坏 conda 安装的文件（nvcc.exe → .c~）：从 pkgs 缓存手动恢复
4. 头文件缺失：Library/include 需复制到环境根 include（含子目录递归）
5. cudart.lib 需复制到 env/lib/x64（torch JIT 的 LIBPATH）
6. `-Wno-attributes` 是 GCC 风格，MSVC 报 D8021 → 修改 gsplat _backend.py 按平台处理
7. torch JIT versioner 不持久化：新进程 import 总会触发重编译，需在 vcvars 环境运行（run_env.bat）
